# 房间分割标注指南 - LabelMe

## 📋 标注目标

使用 LabelMe 对平面图进行语义分割标注，识别：
- **墙壁 (wall)**：平面图中的墙体结构
- **房间 (room)**：各个独立的房间区域
- **门区域 (door_area)**：门的位置
- **窗区域 (window_area)**：窗的位置

---

## 🚀 快速开始

### 启动 LabelMe
```bash
labelme data\images_original --output data\labels_segmentation\json --labels config\segmentation_classes.txt
```

---

## 📝 标注步骤

### 1. 打开图片
- LabelMe 会自动加载 `data/images_original` 文件夹中的图片
- 使用 **Next Image** (D键) 和 **Previous Image** (A键) 切换图片

### 2. 创建多边形标注

#### 标注墙壁 (wall)
1. 点击 **Create Polygons** 或按 **Ctrl+N**
2. 沿着墙壁轮廓点击，勾勒出墙体范围
3. 双击完成多边形
4. 在弹出的标签对话框中输入：`wall`
5. 重复此步骤标注所有墙壁

**提示：**
- 墙壁通常是线条状，宽度较小
- 如果墙壁很细，可以沿墙壁中心线画一条较粗的多边形

#### 标注房间 (room)
1. 点击 **Create Polygons**
2. 沿着房间边界（墙壁内侧）点击
3. 包围整个房间区域
4. 标签输入：`room`
5. 为每个独立房间创建一个多边形

**提示：**
- 每个房间单独标注为一个多边形
- 不要包含墙壁，只标注房间内部空间
- 客厅、卧室、厨房、卫生间都算独立房间

#### 标注门区域 (door_area)
1. 在门的位置创建小多边形
2. 标签输入：`door_area`
3. 标注所有门的位置

#### 标注窗区域 (window_area)
1. 在窗的位置创建小多边形
2. 标签输入：`window_area`
3. 标注所有窗的位置

### 3. 保存标注
- 按 **Ctrl+S** 保存当前图片的标注
- 标注会保存为 JSON 文件到 `data/labels_segmentation/json/`

### 4. 继续下一张
- 按 **D** 键切换到下一张图片
- 重复标注过程

## 🎯 标注标准

### 优先级
1. **墙壁 (wall)** - 最重要，必须标注
2. **房间 (room)** - 最重要，必须标注
3. **门区域 (door_area)** - 重要，尽量标注
4. **窗区域 (window_area)** - 可选

### 质量要求
- ✅ 沿着墙壁/房间边界精确点击
- ✅ 多边形应该闭合且无交叉
- ✅ 每个类别的标签名称要一致（不要打错字）
- ✅ 房间之间不要重叠

### 标注建议
- **从简单到复杂**：先标注结构清晰的平面图
- **从大到小**：先标注墙壁和房间，再标注门窗
- **保持一致**：所有图片使用相同的标注规则
- **定期保存**：每标注几个多边形就按 Ctrl+S 保存

## 🔍 标注示例

### 简单平面图（推荐第一批标注）
```
[客厅] --门-- [卧室1]
   |
  门
   |
[卧室2] --门-- [卫生间]
```

**标注顺序：**
1. 先用 `wall` 标注所有墙壁
2. 在墙壁内部用 `room` 标注 4 个房间
3. 用 `door_area` 标注 3 个门的位置

### 复杂平面图（第二、三批标注）
- 多个房间
- 不规则形状
- 多个门窗

## 🐛 常见问题

### Q: 多边形画错了怎么办？
**A:** 选中错误的多边形，按 **Delete** 删除，重新画

### Q: 标签名称输错了怎么办？
**A:** 选中多边形，右键选择 **Edit Label**，修改标签名称

### Q: 房间形状不规则怎么标注？
**A:** 尽量多点击几个点，精确勾勒房间轮廓

### Q: 墙壁很细怎么标注？
**A:** 沿着墙壁画一条稍粗的多边形，宽度约为墙壁实际宽度

### Q: 需要标注家具吗？
**A:** 不需要！家具已经在目标检测中标注了，这里只标注房间结构

### Q: 保存后发现标注错误怎么办？
**A:** 重新打开该图片，修改后再次保存即可

## 💡 标注技巧

### 提高效率
- 使用快捷键而不是鼠标点击菜单
- 先完成一张图片的所有墙壁，再标注房间
- 标注 5-10 张后休息一下，保持注意力

### 提高质量
- 放大图片查看细节（鼠标滚轮）
- 对比已标注的图片，保持一致性
- 不确定的地方可以稍微放宽边界
